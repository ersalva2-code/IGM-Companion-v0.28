IGM COMPANION 0.28 — Windows x64 / .NET Framework 4.8

NOVEDADES 0.28

al Companion instalado en Binaries\IGM. Se combinan alianzas por ID y sistemas por
direccion/planeta, sin duplicados. Se conservan los nombres e iconos locales.
Si el archivo no existe, se usa solo el save. Si no se puede leer, se informa.
Los conflictos quedan sin seleccionar y excluidos de exportacion automatica.
Leer y combinar no modifica los archivos de IGM; se escribe al pulsar Exportar.
Con los dos saves y el catalogo aportados: 75 sistemas y 11 alianzas, 0 conflictos.
Se reconocen los nombres de contexto activo Main, Expedition y Season.

INSTALACION / ACTUALIZACION
Cierra No Man's Sky. Copia IGM_Companion.exe dentro de tu carpeta existente:
Steam\steamapps\common\No Man's Sky\Binaries\IGM\
Sustituye solo el EXE del Companion. NO borres ni reemplaces la carpeta IGM
ni IGM_datos. Este paquete no contiene ni modifica el DLL de IGM.
Los antiguos Languages.json, Symbols, PNG, ICO y config externos ya no son
necesarios para 0.28; este ZIP no los incluye ni los elimina de tu instalacion.
Si ejecutas el programa desde otro sitio, selecciona la carpeta del IGM instalado
cuando te lo pida. No selecciones la carpeta de otra partida por accidente.

USO
Carga un save .hg, el archivo de datos real de Xbox PC o JSON decodificado.
No selecciones el indice ni los metadatos del save. Los saves solo se leen.
Revisa las alianzas, las estaciones propias y los registros seleccionados.
Se conserva el editor y la galeria de 178 simbolos originales.
"Esta es mi alianza" puede asignar la alianza elegida a tus estaciones propias
sin ID confirmado, usando el propietario del save; no reasigna otros sistemas.
Las cache de alianzas no son una verificacion del servidor.
Exporta con el juego cerrado y vuelve a abrir NMS para cargar los cambios.
La seleccion de propietario no se adivina si hay varios propietarios ambiguos.
